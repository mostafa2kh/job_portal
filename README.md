📖 About the Project

The Job Portal is designed to streamline recruitment by offering:

Employer Dashboard: Post jobs, filter applicants, and manage listings.

Job Seeker Profile: Create resumes, track applications, and receive job recommendations.

Search & Filters: Advanced search by keywords, location, experience, and skills.

Notifications: Real-time alerts for new matches and application status updates.

This platform supports secure authentication, role-based access control, and a responsive design for all devices.
